# Sentiment Detector GUI

This project is a graphical user interface (GUI) application built with Python's Tkinter library that performs sentiment analysis using the VADER SentimentIntensityAnalyzer. It allows users to input a sentence and provides an analysis of the sentiment as positive, neutral, or negative, along with a summary of the overall sentiment.

## Features
- Enter a sentence to analyze sentiment.
- Displays percentage values for negative, neutral, and positive sentiments.
- Provides an overall sentiment classification (Positive, Neutral, or Negative).
- Simple and user-friendly interface.
